# Импорт знаний из Markdown

Импортируй только папку или файлы, которые пользователь явно попросил скопировать в 247C. Такое поручение разрешает импорт этих документов. Досье задач и предложения из разговоров обрабатываются прежним порядком с утверждением в панели.

Публичный RPC `importKnowledge` принимает `requestId` (UUID), `source` (`label`, `hostId`, абсолютный `rootPath`) и `documents`. У документа обязательны относительный путь `.md`, `title` и полный UTF-8 `body`; необязательны `tags` и `modifiedAt` (UTC ISO timestamp или null). Получается снимок текста, а не ссылка, читаемая динамически. Исходный файл и досье не изменяются.

Читай файл как байты и декодируй UTF-8 без нормализации переводов строк. Сохраняй Markdown, frontmatter и все разделы. Заголовок и теги служат навигации и не заменяют тело документа. Файлы конфигурации Git не являются статьями. Пределы: 128 КиБ на тело, 500 документов и 4 МиБ JSON на запрос; удобно отправлять пакеты до 384 КиБ. Проверь ограничения до первого импорта и сообщай о пропущенных файлах, не обрезай их незаметно.

RPC вызывается POST-запросом JSON к `/api/v1/plugins/247c/rpc/importKnowledge` на текущем сервере BB. Ответ содержит `imported`, `updated`, `unchanged`, `documents`. Один пакет сохраняется в транзакции. При повторе запроса используй прежний UUID и точно тот же ввод; для нового снимка создай новый UUID. Идентичность документа определяется компьютером, корневой папкой и относительным путём. Удаление файла из исходной папки не удаляет уже импортированную копию.

Через RPC `knowledge` или `c247_knowledge` ищи по тексту и передавай возвращённый `nextOffset` в следующий `offset`, пока он не станет null. Страница содержит до 50 записей; большие документы уменьшают число записей в ответе, чтобы он оставался ограниченным. CLI: `bb 247c knowledge [query] --offset N --json`.

После переноса пройди все страницы, проверь полный набор относительных путей, точное совпадение текстов и SHA-256 с источниками. Проверь сохранность прежних записей из разговоров. Не создавай фиктивные задачи, сессии или утверждения ради импорта. Импортированные файлы имеют `kind: file`; записи разговоров — `kind: conversation`.
