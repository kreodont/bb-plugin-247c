# Настройка источников

Настройка BB `sources` содержит JSON по примеру [sources.example.json](sources.example.json). Сохрани свою заполненную копию вне репозитория. Это конфигурация поиска и аккаунта; токены и пароли сюда не вставляются.

Плагин читает сохранённый вход Claude из указанного `profilePath`: на macOS через Связку ключей, на других системах через файл, который создал сам Claude. Войди в этот профиль штатным Claude CLI и подключи нужные коннекторы. `expectedEmail` обязателен: плагин проверяет совпадение аккаунта. Профиль по умолчанию `~/.claude-work`; он может указывать на другой профиль. Для обновления входа нужен `claude` на PATH сервера BB.

`jiraSite` ограничивает чтение конкретным сайтом Jira. `jiraScope` — условие JQL внутри временного интервала. `slackChannels` — имена каналов для поиска, `slackGroups` — ID групповых чатов для чтения истории. `mailFilters` добавляется к общему поиску писем; непрочитанный inbox проверяется отдельно. `analysisContext` объясняет модели обязанности владельца, не содержит секретов и передаётся в анализ. Поле `calendarId` выбирает календарь; `primary` заменяется на `expectedEmail`.

Применить локальную копию файла без shell-интерполяции:

```python
import json, subprocess
from pathlib import Path
profile = json.loads(Path("/path/to/sources.private.json").read_text())
subprocess.run(["bb", "plugin", "config", "247c", "set", "sources", json.dumps(profile)], check=True)
```

В интерфейсе настройка доступна через Extensions → Plugins → 247C. Проверь источники вручную, выбрав доступную модель и рабочую папку. Затем можно включить `hourlyUpdates`: 08:00–20:00 ежедневно в Europe/Athens. `calendarMeetings` управляет календарём. Модели и подключённые аккаунты оплачиваются/ограничиваются выбранным провайдером.

Смена календаря не изменяет прошлые встречи другого календаря. Неверный аккаунт или отсутствие входа сохраняет прежние данные и показывает ошибку. Установка кода на другом компьютере не переносит этот профиль и не синхронизирует базы.
